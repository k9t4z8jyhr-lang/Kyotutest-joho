📚 書き方ガイド（基本・実例・使える書き方）

① プログラムの基本ルール


・プログラムは上から1行ずつ順番に実行されます。
・= は「代入」（右の値を左の変数に入れる）。「等しいか」を調べるときは == を使う。
・「繰り返す:」「ならば:」の中身は字下げ（スペース4つを目安）して書きます。字下げがそろっている部分がひとまとまりです。
・結果は 表示する(…) で出力。複数をカンマで並べると、つなげて表示されます。
・配列は A[i] のように添字で要素を指定。添字が 1 始まりか 0 始まりかは、上の「配列の添字」で切り替えます。
・行頭に # をつけるとメモ（コメント）になります。「(01)」の行番号や「│」を貼り付けても動きます。


② 実例（このままコピーして実行できます）


例1：変数と表示
x = 3
y = x * 2 + 1
表示する("y の値は", y)
→ y の値は7


例2：配列と合計（繰り返し）
A = [3, 1, 4, 1, 5]
n = 要素数(A)
goukei = 0
i を 1 から n まで 1 ずつ増やしながら繰り返す:
    goukei = goukei + A[i]
表示する(goukei)
→ 14（添字が 0 始まりのときは「1 から n まで」を「0 から n - 1 まで」にする）


例3：条件分岐（もし）
x = 7
もし x % 2 == 0 ならば:
    表示する("偶数")
そうでなければ:
    表示する("奇数")
→ 奇数


例4：回数が決まっていない繰り返し
x = 1
x < 50 の間繰り返す:
    x = x * 2
表示する(x)
→ 64（1→2→4→8→16→32→64 となり、50以上で終わる）


例5：最大値を求める（もし・繰り返しの組み合わせ）
A = [3, 8, 2, 6]
n = 要素数(A)
saidai = A[1]
i を 2 から n まで 1 ずつ増やしながら繰り返す:
    もし A[i] > saidai ならば:
        saidai = A[i]
表示する(saidai)
→ 8


例6：関数と計算
表示する(最大値(3, 8))
表示する(最小値(3, 8))
表示する(整数(7 / 2))
表示する(7 % 3)
→ 8 / 3 / 3 / 1（それぞれ1行ずつ表示）


③ よくあるミス


・=（代入）と ==（比較）を取り違える
・合計や個数を 0 で初期化し忘れる（「まだ代入されていません」とエラーになります）
・繰り返しの範囲を 1〜n と 0〜n-1 で間違える（範囲外の添字エラーの原因）
・「の間繰り返す」の中で条件の変数を更新しない（無限ループ）
・字下げをそろえない（字下げがずれるとエラーになる、または繰り返しの外に出てしまう）
・「表示する」を繰り返しの中にするか外にするかを間違える（毎回表示されるか、最後に1回かが変わる）


④ デバッグのコツ


「⏭ ステップ」で 1 行ずつ、または「⏩ 連続ステップ」で自動的に進め、「変数のようす」の変化を見ると、どこで考えがずれたか分かります。エラー表示には行番号が出ます。
